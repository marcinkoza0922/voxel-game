# Biome designs

These pages record current biomes and ideas for future world generation. The
game uses Polar for its permanently snowy terrain. Tundra is the planned name
for cold terrain with partial snow cover.
See the [current terrain design](../DESIGN.md#regional-terrain-variants).

## Structures and other locations

The proposal also calls for occasional temples, ruins, labyrinths, and other
mysterious structures. Dune temples and pyramids are part of the dune draft.
Sunken ships and ruins can appear within underwater biomes. Ancient ruins of a
lost civilization can appear within underground biomes. Floating islands are a
separate world feature planned well away from the starting area.
